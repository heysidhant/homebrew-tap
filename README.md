# heysidhant/tap

Homebrew casks for Mac apps by [Sidhant Sinha](https://github.com/heysidhant).

```sh
brew install --cask heysidhant/tap/pixtamer
```

| Cask | App |
|---|---|
| `pixtamer` | [Pixtamer](https://github.com/heysidhant/pixtamer): batch image optimiser for the web (free, open source) |
