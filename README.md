# heysidhant/tap

Homebrew casks for Mac apps by [Sidhant Sinha](https://github.com/heysidhant).

```sh
brew tap heysidhant/tap
brew trust heysidhant/tap     # Homebrew asks you to trust third-party taps once
brew install --cask agentknocks   # or pixtamer
```

| Cask | App |
|---|---|
| `agentknocks` | [AgentKnocks](https://agentknocks.com): menu-bar alerts when a Claude Code or Codex session needs you (free, Pro one-time) |
| `pixtamer` | [Pixtamer](https://github.com/heysidhant/pixtamer): batch image optimiser for the web (free, open source) |
